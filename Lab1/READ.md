# 高性能计算实验：Cache优化与指令级并行性能分析

## 实验内容

本实验探究现代计算机体系结构中 **Cache局部性** 和 **指令级并行** 对程序性能的影响，包含两个任务：

1. **矩阵列内积**：对比“逐列访问”（平凡算法）与“按行访问”（Cache优化）的性能
2. **数组求和**：对比“链式累加”（平凡算法）与“两路累加”（指令级并行优化）的性能

## 实验环境

- **CPU**: Intel Core i7-14650HX @ 2.20GHz
- **内存**: 16.0 GB
- **操作系统**: Windows 11 家庭中文版
- **编译器**: g++ 8.1.0 (MinGW-W64)
- **优化级别**: -O2

## 文件说明

- `benchmark.cpp` - 完整实验代码
- `report.pdf` - 实验报告
- `report.tex` - 实验报告 LaTeX 源文件

## 快速运行

### 编译
`g++ -O2 -std=c++11 benchmark.cpp -o benchmark`

### 运行
`./benchmark`

## 实验结果摘要

- **Cache优化效果**：矩阵列内积最高获得 **5.68倍** 加速比
- **指令级并行效果**：数组求和（小规模）获得约 **2倍** 加速比
- **性能瓶颈**：小规模时计算能力是瓶颈，大规模时内存带宽成为主要限制因素
